Télécharger RIFU pour Windows

L'installeur de la dernière version, puis cinq étapes pour être prêt avant votre prochaine partie. RIFU est gratuit et se met à jour tout seul, jamais pendant une partie.

Télécharger l'installeur

Windows 10 et 11 · installeur sur la page des versions

  • Fichier RIFU-Setup-….exe
  • Système Windows 10 ou 11, 64 bits
  • Serveur EUW
  • Accès Code bêta personnel
Demander mon code bêta sur Discord

Le bouton ne lance rien ? Prenez l'installeur sur la page officielle des versions (fichier .exe). Chaque version y publie aussi son empreinte SHA-256.

Guide d'installation

Cinq étapes, deux minutes

  1. Ouvrez le fichier téléchargéRIFU-Setup-….exe, dans votre dossier Téléchargements. Aucun droit administrateur requis.
  2. Passez l'avertissement de WindowsPendant la bêta, l'installeur n'est pas encore signé, donc Windows le signale. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».
    Windows a protégé votre ordinateur Microsoft Defender SmartScreen a empêché le démarrage d'une application non reconnue. Informations complémentaires
    Exécuter quand mêmeNe pas exécuter

    Illustration de la fenêtre de Windows.

  3. Entrez votre code bêtaIl est personnel. Pas encore de code ? Demandez-le sur le Discord RIFU.
  4. Lancez LeagueRIFU détecte votre compte tout seul et prépare votre pool à partir de votre maîtrise. Vous pouvez le modifier.
  5. Passez en fenêtré sans bordurePour voir les overlays en partie : Options › Vidéo › Mode d'affichage, dans League.

Bon à savoir

  • Environ 100 Mo à télécharger
  • Mises à jour automatiques, jamais pendant une partie
  • App en français ou en anglais, dans Réglages › Langue
  • Sans client Overwolf à installer
  • API officielles de Riot uniquement, aucune lecture de la mémoire du jeu

Raccourcis

  • Ctrl + X : panneau en partie
  • TAB maintenu : écarts d'équipement
  • Espace au chargement : voir l'écran de League
  • Ctrl + K : aller à un écran
