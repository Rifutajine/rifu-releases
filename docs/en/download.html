Download RIFU for Windows

The latest installer, then five steps to be ready before your next game. RIFU is free and updates by itself, never during a game.

Download the installer

Windows 10 and 11 · installer on the releases page

  • File RIFU-Setup-….exe
  • System Windows 10 or 11, 64-bit
  • Server EUW
  • Access Personal beta code

Button not working? Get the installer from the official releases page (the .exe file). Each release also publishes its SHA-256 checksum there.

Five steps, two minutes

  1. Open the downloaded fileRIFU-Setup-….exe, in your Downloads folder. No admin rights needed.
  2. Get past the Windows warningDuring the beta the installer isn't signed yet, so Windows flags it. Click “More info”, then “Run anyway”.
    Windows protected your PC Microsoft Defender SmartScreen prevented an unrecognised app from starting. More info
    Run anywayDon't run

    Illustration of the Windows dialog.

  3. Enter your beta codeIt's personal. No code yet? Ask for one on the RIFU Discord.
  4. Launch LeagueRIFU detects your account by itself and builds your pool from your mastery. You can change it.
  5. Switch to borderlessTo see the overlays in game: Options › Video › Window Mode, in League.

Good to know

  • About 100 MB to download
  • Automatic updates, never during a game
  • App in English or French, in Settings › Language
  • No Overwolf client to install
  • Official Riot APIs only, no reading of the game's memory

Shortcuts

  • Ctrl + X : in-game panel
  • Hold TAB: item gaps
  • Space on the loading screen: show League's screen
  • Ctrl + K : jump to a screen
