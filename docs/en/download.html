Installation guide

Five steps, two minutes

  1. Open the downloaded fileRIFU-Setup-….exe, in your Downloads folder. No admin rights needed.
  2. Get past the Windows warningDuring the beta, the installer isn't signed yet, so Windows flags it. Click “More info”, then “Run anyway”.
    Windows protected your PC Microsoft Defender SmartScreen prevented an unrecognized app from starting. More info
    Run anywayDon't run

    Illustration of the Windows prompt.

  3. Enter your beta codeIt's personal. Don't have one yet? Ask for it on the RIFU Discord.
  4. Launch LeagueRIFU detects your account by itself and builds your pool from your mastery. You can edit it.
  5. Switch to borderlessTo see the overlays in game: Options › Video › Window Mode, inside League.

Good to know

  • About 100 MB to download
  • Automatic updates, never during a game
  • App in English or French, in Settings › Language
  • No Overwolf client to install
  • Official Riot APIs only, never reads game memory

Shortcuts

  • Ctrl + X : in-game panel
  • Hold TAB: item gaps
  • Space on the loading screen: show League's screen
  • Ctrl + K : jump to a screen
